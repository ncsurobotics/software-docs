# Active Learning Pipeline

The team has preserved this link to an [Active Learning test repository](https://github.com/Z-Man-M/SW-ALP-test). Active learning is a workflow for improving a vision model by collecting examples, labeling or reviewing uncertain cases, training a revised model, and validating whether it performs better on the task that matters.

This page is intentionally a starting point rather than a deployment guide. The SW9S source contains more than one vision-related path, and the current model storage/promotion process needs team confirmation before this handbook describes how a trained model reaches the vehicle.

See the [Team-Confirmation Register](../reference/team-confirmation-register.md) for the questions that need resolution first.
